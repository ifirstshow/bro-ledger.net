# 计划 ⑤/⑤：AOT 发布矩阵 + CI + 验收 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 三平台 Native AOT 发布矩阵 + GitHub Actions CI 门 + 计划①-④携带项收口 + 规格 §9 验收清单执行——项目交付。

**Architecture:** CI 在 GitHub Actions 三 OS matrix 上跑测试与 4 RID AOT 发布（`TreatWarningsAsErrors` 全步骤零容忍）。发布配置收敛在 App.csproj（CLI 参数可覆盖）。携带项按终审 triage 硬门逐项落地。手动验收项（真 Worker 互通、像素并排、Java 并排）明确为用户执行步骤并给出操作说明。

**Tech Stack:** 同前四计划；无新 NuGet 包。GitHub Actions（ubuntu-latest / windows-latest / macos-latest，.NET 10 SDK）。

**Spec:** `docs/superpowers/specs/2026-10-10-bro-ledger-csharp-avalonia-design.md`（§6 AOT 规范、§9 验收标准、§5.5 分享互通）

**计划①-④携带项**（终审 triage 硬门）：① Cmd/Meta 快捷键映射（macOS 发布必须）② 真 Worker 分享互通手验 ③ 像素级并排核验（含辉光/滚动条 hover/行拖拽/弹窗阴影四项留验）④ msbuild 时间戳注入 version.properties ⑤ BROLEDGER_DATADIR 测试竞态 + headless 泵循环 CI 诊断。**长期保留项不进本计划**（IsUnderConsumed 收敛、SaveUiState 对称化、观感微漂类）。

## Global Constraints

- 沿用前四计划全部 Global Constraints
- **CI 门（规格 §6 逐字）**：构建/publish 均带 `-p:TreatWarningsAsErrors=true`——AOT/trimmer 警告（IL2000–IL2099、IL3000–IL3007、IL3050–IL3056）零容忍；`dotnet test` 全绿 + `dotnet publish -c Release -r <rid>` 三平台成功为验收门
- 发布矩阵（规格 §6）：`win-x64`、`linux-x64`、`osx-arm64`、`osx-x64`；App 单文件自包含（PublishAot 已设，`PublishSingleFile`/`SelfContained` 随 AOT 默认，不显式重复设置——YAGNI）；Tools 不在发布矩阵（规格 §1 非目标：AOT 单文件产物即交付物指 App）
- 快捷键映射裁决：Java `SHORTCUT_DOWN` 语义 = macOS Cmd / 其余 Ctrl → `OperatingSystem.IsMacOS() ? KeyModifiers.Meta : KeyModifiers.Control`（运行时判定，一处 helper）
- 版本戳：msbuild Target 写 `obj/version.properties`（`version=yyyyMMddHHmm` UTC 分钟级——对齐 pom `maven.build.timestamp` 格式）+ EmbeddedResource 改指向；源码树里的静态副本移除或降级为 fallback
- 手动验收项**不自动执行**：真 Worker 发布是对共享基础设施的可见副作用——由用户本人执行（Task 6 给出操作说明），或经用户明确授权后才可代跑
- 本机无 Java 工具链：Java 并排验收为格式级互认 + 用户自验（不装 JDK）
- 无新测试框架；新钉测试沿用 xUnit 双栈现状

## Review Focus

1. **AOT 发布产物完整性**：App 单文件可启动、字体/图标/嵌入资源随包、设置窗口可用 → Task 4 本机 win-x64 实测 + Task 5 CI 三平台
2. **CI 门真实性**：TreatWarningsAsErrors 若有既有警告会直接红——先本地预演（Task 4）再上 CI；macOS/linux 上 headless 测试（Avalonia Headless 无显示器依赖）与路径分隔符/大小写敏感差异 → Task 5 CI 首跑盯满
3. **快捷键平台映射**：macOS Meta 不破坏 Windows/Linux Ctrl；ESC 链不受影响 → Task 2 headless 钉 + 手验
4. **测试竞态根除**：BROLEDGER_DATADIR 收敛后连跑 10 次稳定（含 CI runner 双核慢机模拟 `-- xunit maxParallelThreads`）→ Task 1
5. **版本戳随构建更新**：两次构建产生不同时间戳、嵌入资源生效、title-bar 显示 → Task 3 钉
