## Global Constraints

- 沿用前三计划全部 Global Constraints（1:1 行为规则、零警告、source-gen JSON、单例 Collection 纪律）
- **JavaFX → Avalonia 映射表**（全计划统一，不逐任务重述）：
  - BorderPane→`DockPanel`、HBox/VBox→`StackPanel`（对齐/间距用属性表达）或 `Grid`、ScrollPane→`ScrollViewer`、Label→`TextBlock`、Region 弹簧→`Grid` 星号列
  - `fx:id`→`x:Name`、`styleClass`→`Classes`、`onAction`→`Command` 绑定、`ObservableList`→`ObservableCollection`
  - `Platform.runLater`→`Dispatcher.UIThread.InvokeAsync`；`Stage`→`Window`；undecorated stage 自绘标题栏→`ExtendClientAreaToDecoratesHint="True"` + 手绘拖拽/最小化/最大化/关闭
  - `FileChooser`→`StorageProvider.OpenFilePickerAsync`；`Timeline` 动画→`DispatcherTimer`
- **keeper.css 翻译规则**：`.cls`→选择器 `Classes.cls`；`:hover`→`:pointerover`；`:pressed`→`:pressed`；颜色/字号/间距/padding 数值原样；`-fx-*` 前缀去除；多值 background→`Background` 渐变或 Border 叠加（语义等价，记录无法 1:1 的条目）
- **MVVM 规则**：可绑定状态→`[ObservableProperty]`；命令→`[RelayCommand]`；纯视觉子组件（StarsWidget/BrotherListCell/PerkPlanPane/总览表行）→自定义控件（`TemplatedControl` 或 `UserControl`）；Controller 中**无状态**工具方法→静态类
- **视觉验收基准**：布局结构、颜色、字体、间距与 Java 版并排一致（冒烟时两版并开比对）；不要求像素级
- App 项目设 `PublishAot=true`（全解决方案唯一）；资源嵌入 LogicalName 保持 `BroLedger.Core.*`/新增 `BroLedger.App.*` 前缀
- 计划②携带项落地：PerkSortMode 补 `Label/Next()`（App 层 `PerkSortModeLabels.cs` 静态扩展，见 Task 1）；ImageCache App 层（LRU 300 + 1×1 灰 PNG 字节常量，Java `ImageCache.java` L69-79）；**visualLayerMap 消费序（定稿）**：Java `LinkedHashMap` 迭代序 = 插入序，C# `Brother.VisualLayerMap` 若 UI 需要按层序合成画像，消费处改用 `List<KeyValuePair<string, VisualLayer>>` 快照排序，不改 Core 模型
- 计划③移交项落地确认：attachment icon 并排核对（计划⑤真 .dat 手验时执行）；PerkComparator OFF→Ordinal **已修**（计划②修复波 a493621，无需再动）
- Bro Developer（规格 §1 功能）：Expected 编辑器/auto-assign/remainder 计数/Naive-Greedy 偏好——归属 Task 4 兄弟卡片
- 新 NuGet 包仅限：Avalonia（12.x 全家桶）、Avalonia.Controls.DataGrid、CommunityToolkit.Mvvm、Avalonia.Themes.Fluent（或 Simple——以最接近 keeper.css 深色主题者为准，报告记录）；测试：App.Tests 用 xunit 同款
